# VitrinaOps

E-ticaret magaza kurulumu, urun gorseli duzenleme, urun girisi ve katalog yonetimi icin tanitim sitesi. Next.js App Router ve DaisyUI ile hazirlanmistir.

## Yerel gelistirme

```bash
npm install
npm run dev
```

Uygulama `http://localhost:3000` adresinde acilir.

## Kontroller

```bash
npm run lint
npm run build
```

## Vercel

Depoyu Vercel projesine baglayin. Framework preset olarak Next.js algilanir; varsayilan `npm run build` komutu kullanilabilir. Uygulamanin su an icin ortam degiskenine ihtiyaci yoktur.
